## Настройка Render.com

### 1. Регистрация

1. Перейдите на [render.com](https://render.com)
2. Нажмите **"Get Started"** или **"Sign Up"**
3. Войдите через **GitHub** (рекомендуется для автодеплоя)

### 2. Создание нового сервиса

1. На главной странице Render Dashboard нажмите **"New +"**
2. Выберите **"Blueprint"** (так как у нас есть `render.yaml`)
3. Подключите ваш GitHub репозиторий
4. Render автоматически обнаружит `render.yaml`

### 3. Настройка переменных окружения

> [!IMPORTANT]
> Вам нужно настроить следующие переменные окружения в Render Dashboard:

#### Обязательные переменные:

| Переменная | Значение | Где взять |
|------------|----------|-----------|
| `TELEGRAM_BOT_TOKEN` | `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz` | Получите от [@BotFather](https://t.me/BotFather) в Telegram |
| `ADMIN_PASSWORD` | `ваш_надежный_пароль` | Придумайте сильный пароль для админ панели |

#### Автоматически настроенные:

- `SESSION_SECRET` - генерируется автоматически
- `PORT` - установлен на 10000 (стандарт Render)
- `NODE_ENV` - установлен на "production"
- `TZ` - установлен на "Asia/Tashkent"
- `ADMIN_USERNAME` - "admin"
- `DATABASE_PATH` - `/var/data/clients.db`

### 4. Настройка Persistent Disk

Render автоматически создаст диск для базы данных согласно `render.yaml`:
- **Имя:** `cosmo-data`
- **Путь монтирования:** `/var/data`
- **Размер:** 1 GB (бесплатно)

> [!NOTE]
> Persistent disk гарантирует, что ваши данные (клиенты, промоушены) не будут удалены при перезапуске сервера.

## Деплой приложения

### 1. Запуск деплоя

1. После настройки переменных нажмите **"Apply"** или **"Create Blueprint"**
2. Render начнет автоматический деплой:
   ```
   ✓ Клонирование репозитория
   ✓ Установка зависимостей (npm install)
   ✓ Запуск сервера (npm start)
   ```

### 2. Ожидание

- Первый деплой может занять **3-5 минут**
- Следите за логами в реальном времени в Dashboard

### 3. Получение URL

После успешного деплоя вы получите URL вида:
```
https://cosmo-birthday-app.onrender.com
```

## Устранение проблем

### ❌ Ошибка: "Telegram bot не запускается"

**Причина:** Неверный `TELEGRAM_BOT_TOKEN`

**Решение:**
1. Проверьте токен в Render Dashboard → Environment
2. Убедитесь, что скопировали весь токен от BotFather
3. Сохраните изменения и перезапустите сервис

### ❌ Ошибка: "Cannot login to admin panel"

**Причина:** Неверный пароль или не установлена переменная `ADMIN_PASSWORD`

**Решение:**
1. Проверьте переменные окружения в Render
2. Установите `ADMIN_PASSWORD`
3. Перезапустите сервис
4. Попробуйте войти с новым паролем

### ❌ Ошибка: "Database is empty after restart"

**Причина:** Persistent disk не подключен

**Решение:**
1. В Render Dashboard откройте ваш сервис
2. Перейдите на вкладку **"Disks"**
3. Убедитесь, что диск `cosmo-data` создан и подключен к `/var/data`
4. Если нет - создайте вручную через Blueprint или вкладку Disks

### ❌ Ошибка: "Application Error" или 503

**Причина:** Сервер не запустился

**Решение:**
1. Проверьте логи в Render Dashboard
2. Убедитесь, что все зависимости установлены
3. Проверьте, что `npm start` работает локально
4. Проверьте порт (должен использоваться `process.env.PORT`)

### ❌ База данных не инициализируется

**Решение:**
1. Добавьте команду инициализации в `startCommand` в `render.yaml`:
   ```yaml
   startCommand: "node database/init.js && npm start"
   ```
2. Или создайте пустую базу локально и закоммитьте её в Git
